# Calendario público

`/usersCalendar` muestra las presentaciones abiertas al público con sus flyers cuando están disponibles. El mes inicial corresponde a la próxima fecha publicada. Se puede navegar a otros meses y filtrar por categoría. Las tarjetas de shows y clases permiten consultar por WhatsApp.

La cartelera se edita siguiendo el [protocolo de calendarios](../../docs/calendarios.md).
